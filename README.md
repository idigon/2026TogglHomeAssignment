# Toggl 2.0 — Projects

A pixel-faithful rebuild of the Toggl 2.0 **Projects** list view, built as a
practice environment for the Toggl home assignment.

The data is static (see `lib/data.ts`) and mirrors the live workspace: three
projects — Cool feature, New AI project, VIP project.

The earlier **Reports → Summary** rebuild is still here, at `/reports`.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploying to Vercel

The project is a stock Next.js App Router app, so Vercel detects everything
automatically — no `vercel.json` needed.

```bash
npx vercel --prod
```

## Layout

| Path | Purpose |
| --- | --- |

## Design tokens

Sampled from the live app rather than guessed:

| Token | Value | Used for |
| --- | --- | --- |
| `--bg` | `#131213` | App background |
| `--surface` | `#1c1a1c` | Table rows, controls |
| `--line` | `#3c393b` | Row separators, progress track |
| `--control-line` | `#575456` | Control borders; also the active control fill |
| `--billable` | `#c282b9` | Primary button, active nav, billable badge |
| `--over` | `#fab8ac` | Over-budget bar and negative variance |
| `--under` | `#9dcc9f` | Under-budget bar and positive variance |
| `--text-muted` | `#b3b0b2` | Column headers, secondary text |
| `--nav-active-bg` | `#371f34` | Active nav item, billable badge, trial pill |
| `--logo` | `#ec85fe` | Toggl mark |

Project colours come in pairs — a saturated folder icon and a tinted label:
`#36d3b6`/`#c6ece5` (green), `#ee7a63`/`#f3c3b9` (orange), `#9494f9`/`#cacafc`
(blue).

Typeface is Inter at a 14px base, loaded via `next/font`.

## Notes

- The sidebar is a single 248px column with a 36px icon rail down the left. The
  org row spans both; the nav is inset past the rail; the collapse toggle and
  the account/notification/feedback/help buttons sit back in the rail.
- Table column widths were measured off the live app at a 1879px viewport
  (`PROJECT` 341px, `TIME STATUS` 220px, and so on) with a uniform 16px gap.
  Most tracks are `minmax()` so the row compresses toward those measurements on
  narrower screens; below 1086px of table width the section scrolls sideways.
- The time-status bar clamps over-budget projects to a full track and switches
  from `--under` to `--over` — New AI project is at 301%.
- Row checkboxes only appear on hover, as in the real app.
- `AGENTS.md` and `CLAUDE.md` are generated by Next.js 16 on first run.
