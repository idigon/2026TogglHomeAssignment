# Toggl Reports — Summary

A pixel-faithful rebuild of the Toggl 2.0 **Reports → Summary** view, built as a
practice environment for the Toggl home assignment.

The data is static (see `lib/data.ts`) and mirrors one real week of the live
report: week 36, Mon 8/31 – Fri 9/4.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploying to Vercel

The project is a stock Next.js App Router app, so Vercel detects everything
automatically — no `vercel.json` needed.

```bash
git add -A && git commit -m "Toggl reports summary view"
git push          # push to a GitHub repo, then import it at vercel.com/new
```

Or straight from the CLI:

```bash
npx vercel        # preview deploy
npx vercel --prod # production deploy
```

## Layout

| Path | Purpose |
| --- | --- |
| `app/page.tsx` | Page shell: header, toolbar, stat row |
| `app/globals.css` | Design tokens and all component styles |
| `components/Sidebar.tsx` | Left navigation, onboarding card, account footer |
| `components/BillableChart.tsx` | Billable vs non-billable bar chart |
| `components/BreakdownTable.tsx` | Member and task breakdown table |
| `components/Icons.tsx` | Inline SVG icon set |
| `lib/data.ts` | All report values in one place |

## Design tokens

Sampled from the live app rather than guessed:

| Token | Value | Used for |
| --- | --- | --- |
| `--bg` | `#131213` | App background |
| `--surface` | `#1c1a1c` | Cards, controls |
| `--billable` | `#c282b9` | Chart bars, legend |
| `--text-muted` | `#b3b0b2` | Labels, secondary text |
| `--nav-active-bg` | `#371f34` | Active nav item |
| `--logo` | `#ec85fe` | Toggl mark, upgrade icon |
| `--accent` | `#ee7a63` | Trial badge |

Typeface is Inter at a 14px base, loaded via `next/font`.

## Notes

- The chart is hand-rolled with CSS grid rather than a charting library: the
  y-axis is fixed at a 2h 30m ceiling in 30-minute steps, and bar heights are
  `minutes / 150`, matching how the real report scales.
- `AGENTS.md` and `CLAUDE.md` are generated by Next.js 16 on first run.
